Восстановление бэкапа
⚠️ ВНИМАНИЕ!
Восстановление из бэкапа полностью удалит все текущие данные: пользователей, курсы, уроки, настройки и медиафайлы.
📁 Файл бэкапа:
backups/{{ filename }}
🚀 Быстрый запуск:
python restore_backup.py {{ filename }}
Скрипт автоматически найдет файл в папке backups/
📋 Что будет восстановлено:
  • База данных (пользователи, курсы, уроки)
  • Медиафайлы (аватары, изображения, файлы)
  • Конфигурация (settings.py, .env)
  • Логи системы
🔄 Пошаговая инструкция восстановления:
Шаг 1: Подготовка системы
⚠️ ВНИМАНИЕ! Это удалит все текущие данные!
  1. Остановите Django сервер: Ctrl+C
  2. Откройте командную строку в папке проекта: cd c:/Progage
  3. Сделайте текущий бэкап (если нужно сохранить данные):
    python manage.py shell -c "from adminpanel.backup_utils import SystemBackup; SystemBackup().create_full_backup()"
Шаг 2: Восстановление базы данных
  1. Удалите текущую базу данных:
    del db.sqlite3
  2. Распакуйте бэкап архив:
    unzip backups/{{ filename }}
  3. Восстановите базу данных из дампа:
    sqlite3 db.sqlite3 < database/database_dump_*.sql
Шаг 3: Восстановление медиафайлов
  1. Сделайте резервную копию текущих медиафайлов (если нужно):
    move media media_backup
  2. Скопируйте медиафайлы из бэкапа:
    xcopy backup\media media /E /I
Шаг 4: Восстановление конфигурации
  1. Резервная копия настроек:
    copy progage\settings.py progage\settings.py.backup
    copy .env .env.backup
  2. Восстановление из бэкапа:
    copy backup\config\progage\settings.py progage\settings.py
    copy backup\config\.env .env
Шаг 5: Запуск системы
  1. Установка зависимостей:
    pip install -r backup\config\requirements.txt
  2. Применение миграций:
    python manage.py migrate
  3. Создание суперпользователя (если нужно):
    python manage.py createsuperuser
  4. Запуск сервера:
    python manage.py runserver
⚠️ ВНИМАНИЕ!
Восстановление бэкапа - это ручная операция, которая требует выполнения команд в командной строке.
Не используйте автоматическое восстановление без полного понимания процесса.
Вернуться к бэкапам
Используйте только ручное восстановление!
Дополнительная информация:
  • Текущие данные будут автоматически сохранены с суффиксом .backup_
  • Процесс восстановления может занять несколько минут
  • После восстановления потребуется перезапуск сервера
  • Все логи операций сохраняются в админ-панели
